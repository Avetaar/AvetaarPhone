# Avetaar Phone Details

أداة تحليل أرقام الهاتف — دولة، مشغل، نوع، صيغة (E164/RFC3966)، مناطق زمنية، علم الدولة، الساعة المحلية، روابط واتساب/مكالمة/خريطة/ويكيبيديا.
تعمل بوجهين من نفس الملف `Avetaar.py`:
- **ترمينال** — بطاقة تفاصيل كاملة بألوان
- **بوت تلكرام** — كل شيء بأزرار ملونة بدون أوامر

## التثبيت بأمر واحد (ويندوز)

```bat
git clone https://github.com/Avetaar/AvetaarPhone && cd AvetaarPhone && python Avetaar.py
```

## التثبيت بأمر واحد (لينكس / ماك)

```bash
git clone https://github.com/Avetaar/AvetaarPhone && cd AvetaarPhone && python3 Avetaar.py
```

الكود يثبّت كل الاعتماديات تلقائيًا أول مرة (phonenumbers, requests, colorama) — مو محتاج تكتب `pip install`.

## التشغيل

```bash
python Avetaar.py          # الترمينال
python Avetaar.py --bot    # البوت
```

## التوكن

التوكن مدمج أعلى الملف:
```python
AVETAAR_BUILTIN_BOT_TOKEN = "T000000000"
```
غيّره لتوكن بوتك. لو ما عبّيته، البوت يسألك عند التشغيل ([1] توكن جديد / [2] تخطي).

## مميزات الترمينال
- تحليل كامل: دولة، مشغل، نوع، صيغة E164/RFC3966، مناطق زمنية
- بطاقة ملونة بألوان
- لا مفاتيح API، 100% مجاني

## مميزات البوت (كل شيء بأزرار ملونة)
- 📞 إدخال رقم + ✅ فحص موبايل + ⚡ فحص سريع (2-5 أرقام) + 🔀 مقارنة رقمين
- 🎲 رقم عشوائي من 8 دول + 📊 آخر 5 فحوصات
- 🏴 علم الدولة + ⏰ الساعة المحلية + 📏 طول الرقم
- 💬 واتساب + 📞 مكالمة + 🗺️ خريطة الدولة + 🌐 ويكيبيديا
- 📋 نسخ E164 / الرقم الوطني بضغطة زر
- تلوين الأزرار: أزرق (إجراء) / أخضر (نجاح) / أحمر (خروج)

## الاستخدام

اكتب رقم الهاتف بأي صيغة:
```
+9647701234567
9647701234567
```

في البوت: كل التفاعل بأزرار — "📞 أدخل رقم" (تكتب الرقم)، "🔍 رقم تجريبي" (يعرض مثال)، "❌ خروج".

## ملاحظات

- الأرقام لازم تبدأ برموز الدولة (964 للعراق، 1 لأمريكا، ...) أو `+`
- لا مفاتيح API ولا رسوم
- البوت محمي من الانقطاع (reconnect تلقائي + نسخة وحدة)
